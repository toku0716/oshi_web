# 推しサポ Web版 (PWA)

推し活総合サポートアプリ「推しサポ」のWeb / PWA版です。

## 主な機能
- **推し管理**: 推しの名前、種類（アイドル、アニメ、VTuber等）、カラー、記念日、メモの登録
- **カレンダー**: ライブ・イベント・出演・チケット申込などの予定管理
- **グッズ管理**: 所持グッズの登録、購入金額集計、保管場所管理
- **マイページ**: データの端末内自動保存（IndexedDB）およびバックアップファイルのダウンロード・復元対応

## 技術スタック
- React 19 + TypeScript
- Tailwind CSS
- Vite + Vite PWA (Service Worker)
- IndexedDB (idb)
