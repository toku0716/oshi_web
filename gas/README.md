# 推しサポ アンケートGoogleフォーム自動作成スクリプト (GAS)

このディレクトリのスクリプトを使用すると、**「推しサポ」の機能や推し活に特化したアンケートGoogleフォーム**と、**回答集計用のGoogleスプレッドシート**をワンクリックで自動作成できます。

作成されたGoogleフォームのURLを「推しサポ」アプリに登録するだけで、アプリ内からユーザーの意見や要望を直接収集できるようになります。

---

## 📋 自動作成されるアンケートの質問項目

1. **利用端末**（スマホ / パソコン / タブレット / 複数端末併用）
2. **アプリ全体の満足度**（1: 不満 〜 5: 大変満足）
3. **特によく使っている機能**（複数選択可：予定・カウントダウン、カレンダー、チケット管理、TODO、グッズ管理、保管場所、推し活支出記録、端末間P2P同期、バックアップ等）
4. **デザインや画面の見やすさ・使いやすさ**（ダークモードや配置の評価）
5. **今後欲しい機能・改善点**（リマインド通知、カレンダー同期、共有、遠征費管理、ウィジェット等）
6. **画面が見づらかった箇所・使いにくかった操作**（自由記述）
7. **自由意見・開発者への応援メッセージ**（自由記述）

---

## 🚀 使い方（所要時間: 約2分）

### ステップ1: Google Apps Script を開く
1. ブラウザで [Google Apps Script](https://script.google.com/) を開きます（Googleアカウントにログイン）。
2. 左上の「**新しいプロジェクト**」をクリックします。

### ステップ2: コードを貼り付ける
1. 表示されたエディタ画面のコード（`myFunction` など）をすべて削除します。
2. [`createSurveyForm.gs`](./createSurveyForm.gs) の内容をすべてコピーして貼り付けます。
3. `Ctrl + S`（Macは `Cmd + S`）で保存します。

### ステップ3: スクリプトを実行する
1. 画面上部のツールバーで「**createSurveyForm**」が選択されていることを確認し、「**実行**」ボタンをクリックします。
2. **初回実行時のみ、Googleの権限承認画面が表示されます：**
   - 「権限を確認」をクリック
   - 自分のGoogleアカウントを選択
   - 「Google による確認が完了していません」と表示されたら、左下の「**詳細**」リンクをクリック
   - 「**無題のプロジェクト（安全ではないページ）に移動**」をクリック
   - 「**許可**」をクリック
3. 実行が完了すると、画面下部の「実行ログ」に以下のようなURLが出力されます。

```text
================================================================
🎉 推しサポ アンケートGoogleフォームの作成が完了しました！
================================================================

【1. アプリ設定用の回答フォームURL】
https://docs.google.com/forms/d/e/1FAIpQLSc.../viewform

【2. アプリ内埋め込み用URL (iFrame用)】
https://docs.google.com/forms/d/e/1FAIpQLSc.../viewform?embedded=true

【3. フォーム編集画面URL】
https://docs.google.com/forms/d/1xxx.../edit

【4. 回答集計スプレッドシートURL】
https://docs.google.com/spreadsheets/d/1yyy.../edit
================================================================
```

### ステップ4: 推しサポアプリに登録する
1. 実行ログに出力された **「【1. アプリ設定用の回答フォームURL】」** をコピーします。
2. 推しサポアプリを開き、「**マイページ**」へ行きます。
3. 「**アンケート・改善要望を送る**」カード内の「**URL設定**」をクリックします。
4. コピーしたURLを貼り付けて「**URLを保存**」をクリックします。

これで設定完了です！以降、ユーザーが「アンケート・改善要望を送る」を押した際に、作成したGoogleフォームが開き、回答内容は自動作成されたスプレッドシートにリアルタイムで蓄積されます。
